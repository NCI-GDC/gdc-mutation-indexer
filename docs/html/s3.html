# Using s3/cleversafe in spark

#### Configure and use S3

The config for the S3 service can be configured in a couple different ways, easiest is to change $SPARK_HOME/conf/spark-defaults.conf:

` spark.hadoop.fs.s3a.access.key=AWS_ACCESS_KEY_ID spark.hadoop.fs.s3a.secret.key=AWS_SECRET_ACCESS_KEY_ID spark.hadoop.fs.s3a.endpoint=ACCESSOR_IP `

Note that the endpoint must be an ip and won’t work with consul services.

Spark uses the hadoop-aws adapter which uses the aws-java-sdk to talk with s3. The sdk enforces stardards held by aws s3 which may vary slightly from those allowed by cleversafe or other s3 interfaces. for instance, hostnames are not typically expected in s3:// url, and bucket names are not allowed to contain underscores.

When working with the s3 adapter, use urls in the following format so that hadoop knows what filesystem protocol to use: s3a://bucketname/key

Here are some examples of ways to interact with the s3 adapter:

```python url = ‘s3a://test/my_file.maf.gz’ f = sc.textFile(url)

rdd = sc.hadoopFile(url,
‘org.apache.hadoop.mapred.TextInputFormat’, ‘org.apache.hadoop.io.Text’, ‘org.apache.hadoop.io.LongWritable’)
df = sqlContext.read.format(‘com.databricks.spark.csv’)
.options(header=’true’).options(codec=”org.apache.hadoop.io.compress.GzipCodec”).load(url)

```
